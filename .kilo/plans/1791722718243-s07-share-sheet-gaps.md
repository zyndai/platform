## Decisions (locked)

1. **Entry UX:** Replace the split "Export / Share | QR" control with a single **Share** button that opens a tabbed dialog. Resume download lives inside the sheet (Link or Card tab). Retire the popover menu and QR popover (fullscreen QR stays, reachable from the QR tab).

3. **Paste preview:** Static client mock unfurl (name, headline, avatar, OG image URL) — no live scraper.
4. **Out of scope:** `zynd.ai/<alias>` apex (dashboard/Caddy), wallet passes, MCP `get_card_status` (S09), paid features.

## Implementation tasks

### 1. Share sheet shell (Web)

Rebuild `ShareQrGroup` in `share-controls.tsx` (or extract `share-sheet.tsx` colocated under `p/[handle]/`):

- Trigger: one button labeled **Share** (Share2 icon); opens dialog.
- Dialog pattern: match `resume-picker.tsx` (`role="dialog"`, `aria-modal`, backdrop click, Escape, focus trap / initial focus on close or first tab). Works at 390px width.
- Tabs: **Link** · **QR** · **Card image** · **Embed & email**.
- Props: extend beyond today’s `{ url, name, handle, avatarUrl, resume }` to include `headline?: string | null` (and optionally `email` / links for vCard download CTAs). Wire from `page.tsx` ~L795.

### 2. Link tab

- Canonical share URL via `withShareRef(url, handle)`; Copy button → `share_click`.
- If card has `alias`, show short URL `cards.zynd.ai/<alias>` (still append `?ref=` when copying) + note that canonical SEO URL remains `/p/<handle>`.
- Share targets (open in new tab / `mailto:`), each firing `share_click` with a `target` property if easy without schema churn; otherwise same event as today:
  - LinkedIn: `https://www.linkedin.com/sharing/share-offsite/?url=`
  - X: `https://twitter.com/intent/tweet?url=&text=`
  - WhatsApp: `https://wa.me/?text=`
  - Email: `mailto:?subject=&body=`
- Static unfurl preview card: avatar, name, headline, domain, thumbnail from `/p/[handle]/opengraph-image`.

### 3. QR tab

- Reuse existing `QRCodeSVG` settings (size ≥272 on-sheet, ≥320 fullscreen, `marginSize={4}`, level M/Q).
- Fullscreen mode + SVG/PNG download (existing helpers `downloadQrSvg` / `downloadQrPng`).
- Quiet-zone visible; keep "Scan to view profile" affordance.

### 4. Card image tab

- "Download Identity Card" → existing `buildIdentityCard` / `onDownload`.
- Optional: "Download Resume" → existing `ResumePicker` (move here from old menu).
- Short note that this PNG is for offline / print, distinct from OG unfurl.

### 5. Embed & email tab (snippets)

Copy-to-clipboard blocks (track `share_click`):

- **Email signature** — HTML + plain: name, headline, link (with ref).
- **LinkedIn Featured** — one-liner + URL instructions.
- **README badge** — markdown: `[![Zynd Card](https://cards.zynd.ai/p/<handle>/badge.svg)](<shareUrl>)`.
- **vCard** — link/button to `/p/[handle]/vcard`.

- OG/twitter image generation cost: keep `revalidate = 3600`.
- `share_click` payload `target` is optional analytics nicety — do not block on backend schema if events are free-form JSON today.
- Identity-card canvas is large; keep it in the same client bundle unless file size becomes painful (split only if needed).
