# Playfair Display

Normal and italic variable fonts, bundled to avoid Google Fonts query-string URLs
that fail in Next.js 16.2.1's font loaders. The layout exposes weights 400–700,
matching the previous Google font configuration.

Source: [google/fonts, commit 8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/playfairdisplay).

- `normal.ttf`: upstream `PlayfairDisplay[wght].ttf`
- `italic.ttf`: upstream `PlayfairDisplay-Italic[wght].ttf`
- `OFL.txt`: upstream SIL Open Font License, version 1.1

Font files are unmodified.
